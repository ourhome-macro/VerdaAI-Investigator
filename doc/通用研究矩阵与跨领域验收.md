# 通用研究矩阵与跨领域验收

## 本轮目标

解决知识管理案例暴露的领域串味、维度遗漏、品牌空洞、来源误判与时效虚标。不是降低置信度标准，也不引入向量数据库。

## 变更设计

- 建立版本化研究契约：品牌、用户指定维度、市场、用户、时间窗口、截止时间。
- 采集、选段、提取、核验、返工、报告使用同一套维度标识；每个品牌×维度独立预算。
- 覆盖标准改成核验通过的原子事实，不再用域名或证据数量代替品牌覆盖。
- 功能、定价、生态、架构要求官方正文；口碑要求可读取的社区原声或独立报道，不能把官方能力介绍当口碑。
- 近一月使用 oneMonth 检索；官方无日期文档可作为背景，但不能充当近期增量。来源发布日期与采集时间分离。
- 缺口按 cell_id 定向补采、重新选段和核验，保留未返工单元；达到预算后明确展示缺口。
- 报告章节由用户维度生成，增加品牌×维度索引及近期来源事实列表。正文审校与研究完整性分别展示。

## 来源登记依据与边界

官方文档入口：[Obsidian 开发文档](https://docs.obsidian.md/)、[飞书开放平台](https://open.feishu.cn/document/home/index)、[Notion 帮助中心](https://www.notion.com/help)、[OneNote 帮助中心](https://support.microsoft.com/en-us/onenote/)、[语雀官方开发者组织](https://github.com/yuque)。

官方域名并不等于页面作者是官方：语雀普通用户空间、Notion 用户页面、飞书租户文档、厂商社区帖子排除在官方声明之外。语雀文档可能返回 403；抓取失败时不把搜索摘要冒充官方正文。

## 验收记录

### 回归与联调过程

- 离线回归已扩充到 77 项，覆盖维度精确映射、20 格完整枚举、品牌空洞、月份/年度时间窗口、官方域名下的用户内容排除、近期段落进入上下文、审阅返工范围校验及断点恢复的维度保留。
- 前端 `npm run build` 与 `npm run lint` 通过；构建仍提示既有主包偏大，本轮未扩展到路由拆包优化。
- 首轮真实案例发现：返工无新事实时会丢弃先前已核验的背景事实，导致品牌再次空洞。现改为保留原来源快照及原日期；出现矛盾时禁止用旧事实救回该单元。保留背景不能提高时效覆盖率。
- 抓取前按来源角色过滤，避免将预算花在无资格的租户页面。语雀补充官方产品/安全页面和官方 SDK、MCP 仓库入口；官方仓库与官网仍归同一个发布者，不能当两个独立来源。
- 社区搜索同时使用短品牌词和平台范围，避免把品牌、地区、用户、体验、评价全部拼成过窄查询；近期检索与历史背景检索分开，历史资料不会补平时效缺口。
- 返工反馈也按单元隔离：不再把所有品牌的全局审阅意见塞进每个品牌的提取提示，避免模型因“缺近期资料”撤销其他品牌已经核验的事实。
- 36 条固定合成 Claim 的真实模型核验评测通过：预设错误放行率 0、unsupported 拒绝率 100%、支持事实召回率 100%、伪交叉验证率 0；最终复测耗时 26 秒、19,175 tokens。它是回归测试，不是实际互联网准确率估计，详见 `通用矩阵-论点核验评测.json`。
- 文章发布时间可以由对应证据的 `published_at` 元数据支持，不因正文引句没有重复该日期误杀；仅精确匹配的文章发布时间适用，产品上市/发布事件日期和普通数值仍受原文数字校验约束。
- `api/app/core` 的 serverless 副本与 `backend/app/core` 同步，核对时仅忽略文件换行差异。
- 前后端联调修复了新的口碑章节与旧聚合面板的契约不一致：最终审校清除未核验统计后，前端不再对空对象读取 `overall.pos` 导致白屏。
- 公开 JSON 样例不上传第三方网页全文、摘要和原文引句；保留 URL、原文偏移、论点与核验结果。完整原文取证快照仍保存在本地数据库，未提交数据库或 `.env`。

### 质量边界

矩阵“一格有事实”只是最低事实覆盖，不等于完整横向可比，也不代表样本具有群体代表性。`final_audit.status=passed` 表示发布正文经过支持性审校；研究完整性和时效仍单独判断，缺口报告保持 `needs_review`。

发布日期不明的在用官方说明可以支撑“页面声明了什么”，但不能证明近一月新增或更新。来源网页时间与产品事件时间分开，不从页面采集时间反推发布时间。无足够社区正文时不生成用户满意度或全网口碑统计。

来源登记是人工审阅配置，不自动信任模型猜出的官网；新品牌需要补充官方范围。NLI 仍是可失误的模型判定，词法选段尚不等于专业语义重排。本轮没有更换搜索引擎、引入向量库或降低可信度门槛。
