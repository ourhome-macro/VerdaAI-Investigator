## 启动与重跑

当前服务由隐藏的后台进程监听本机端口。若电脑重启，需要重新启动：

```powershell
# 后端终端，在 backend 目录执行；使用本机 .env，不改写文件。
$env:REQUIRE_CLIENT_API_KEYS = 'false'
.\.venv\Scripts\python.exe -m uvicorn app.main:app --host 127.0.0.1 --port 8010

# 前端终端，在 frontend 目录执行。
npm.cmd run dev -- --host 127.0.0.1
```

动态官网提取需安装 `backend/requirements-browser.txt` 并运行 `python -m playwright install chromium`。

重新运行完整 UI 验收（会调用付费 API）：

```powershell
# backend 目录
.\.venv\Scripts\python.exe -X utf8 tests/frontend_acceptance.py
```

实现与限制详见 [来源治理与验收记录](../docs/SOURCE_GOVERNANCE_AND_EV_ACCEPTANCE.md)。本次未切换搜索引擎或引入向量数据库；后台执行实现单机租约、事件回放与采集检查点恢复，尚非任意节点的跨机器精确续跑。
